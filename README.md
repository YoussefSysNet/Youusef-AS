# Youssef Ouahman Portfolio

Reference-first portfolio based on the supplied Abhijeet Bhale portfolio source and visual system, with Youssef's real content, three projects, English-only copy, interactive line-wave hero background, scroll animations, custom cursor, centered navigation, and dark/light theme toggle.

Projects: VPN IPsec Site-to-Site, IoT & Smart Home Management, Network Installation & Maintenance.


## Structure des fichiers

- `index.html` : structure et contenu de toutes les sections du portfolio.
- `styles.css` : styles CSS principaux du site.
- `script.js` : animations, interactions et comportements JavaScript.
- `` : photos, visuels des projets et certifications, icônes/images utilisées par le site.
- `` : CV et rapports PDF des projets/stage.
- `backup/` : ancienne sauvegarde de `styles.css`.
